# Termux Neo 1.0.0 Release Notes

Release version: `1.0.0`

Prospective tag: `v1.0.0`

Archive: `termux-neo-1.0.0.tar.gz`

Publication status: stable public release; GitHub release.

## Stable release

- Preserves the feature-frozen render-once runtime, CLI surface, schema-v1
  settings, `neo` and `matrix` themes, and Git-independent lifecycle verified
  by `v1.0.0-rc.1`.
- Passes the complete 26-test quality pipeline, package smoke, internal
  manifest, external archive-and-notes checksum, two-clean-checkout
  reproducibility, and ten-scenario reference-device gates.
- Records zero open critical security, high-severity, or release-blocking
  defects.
- Requires the annotated `v1.0.0` tag to target the verified stable commit and
  all three public assets to match that commit's package bytes.
- Preserves the `v1.0.0-rc.1` commit, annotated tag, prerelease metadata, and
  asset bytes unchanged.

## Public installation

The repository, release page, archive, release notes, and checksum are intended
to be reachable without GitHub authentication. Verify the external checksum
before extraction and the internal `RELEASE_MANIFEST.sha256` before running
`install.sh`. Installation requires no root access and no Git checkout.

The checksum detects changed bytes against the published digest; it is not a
publisher signature and does not make an untrusted download source trustworthy.

## Evidence scope

The physical stable gate covers one Samsung Galaxy Note5 (`SM-N920C`) running
Android `11`, with portrait and landscape terminal widths verified on the real
device. Portable fixtures are not evidence for additional devices, Android
releases, or Termux distribution channels.

## Frozen behavior

Stable promotion changes synchronized release identity and publication
metadata only. It does not add or change runtime commands, settings, themes,
rendering, lifecycle paths, background behavior, or compatibility claims.
