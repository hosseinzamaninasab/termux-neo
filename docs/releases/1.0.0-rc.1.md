# Termux Neo 1.0.0-rc.1 Release Notes

Release version: `1.0.0-rc.1`

Prospective tag: `v1.0.0-rc.1`

Archive: `termux-neo-1.0.0-rc.1.tar.gz`

Publication status: release candidate; GitHub prerelease only.

## Verified candidate

- Preserves the feature-frozen render-once runtime, CLI surface, schema-v1
  settings, `neo` and `matrix` themes, and Git-independent lifecycle.
- Passes the complete 26-test quality pipeline, package smoke, internal
  manifest, external archive-and-notes checksum, and two-clean-checkout
  reproducibility gates.
- Records zero open critical security, high-severity, or release-blocking
  defects.
- Retains the complete MIT-licensed public documentation set and the reviewed
  package allowlist.
- Requires the annotated `v1.0.0-rc.1` tag to target the verified candidate
  commit and the public assets to match that commit's package bytes.

## Evidence scope

The physical candidate gate covers one Samsung Galaxy Note5 (`SM-N920C`)
running Android `11`, with portrait and landscape terminal widths verified on
the real device. Portable fixtures are not evidence for additional devices,
Android releases, or Termux distribution channels.

## Frozen behavior

This candidate changes only synchronized release identity and publication
metadata. It does not add or change runtime commands, settings, themes,
rendering, lifecycle paths, background behavior, or compatibility claims.
Stable `v1.0.0` remains a separate release gate.
